# Recipe: text and translations (gen-l10n)

## Problem

Text typed in widgets turns a second language into a month of work. Catalogs drift: a key missing in one locale
falls back to English without a word, a placeholder typed two ways fails at run time, and dates or money built by
string concatenation read wrong in French and backwards in Arabic.

## Rule

- Every user-facing string comes from the ARB catalogs in `lib/core/l10n/`, through gen-l10n:
  `context.l10n.<key>`. `app_en.arb` is the shape source; every locale has the same keys and placeholders (F11).
- Keys are camelCase, prefixed by feature (`ordersEmptyTitle`). Every placeholder has its type in `@key`.
- Edit every locale together, by small edits: find the key with `grep -n`; never rewrite or read a whole catalog.
- Dates, numbers and money go through `intl`, for the current locale. Layout is right-to-left safe:
  `EdgeInsetsDirectional`, `AlignmentDirectional`, `start`/`end`, never left/right.
- `dart run tool/kit/check_l10n.dart` checks the keys, the placeholders, duplicates and apostrophes.

```dart
// lib/core/common/data/formatters.dart
String formatMoney(int minorUnits, String currency, String locale) {
  final format = NumberFormat.simpleCurrency(locale: locale, name: currency);
  final digits = format.decimalDigits ?? 2;
  return format.format(minorUnits / math.pow(10, digits));
}
```

## Traps

- With `generate: true`, `flutter pub get` runs gen-l10n. After an ARB or `l10n.yaml` edit, run `flutter gen-l10n`:
  a "getter not defined" right after an edit means the generated file is stale, not that the key is missing.
- A key missing in one locale still builds and shows English. `check_l10n.dart` fails it; so does a duplicate key
  (JSON keeps the last of two without a word) and a curly apostrophe (write ' only).
- Server dates are UTC: pass `toLocal()` to a `DateTime` placeholder. Money travels as whole minor units, never
  a double.
- Arabic has six plural forms: `=0`, `=1`, `=2`, `few`, `many`, `other`. Copying the English two forms reads wrong.
- iOS offers the app only the languages listed in `CFBundleLocalizations` (`ios/Runner/Info.plist`): without them
  a French phone opens the app in English.
- A language list names each language in itself (`Français`, `العربية`), so a user lost in the wrong language
  still finds theirs.
- Tests read the catalog (`l10nEn.ordersEmptyTitle` from `test/helpers/pump_app.dart`); they never retype text.
- A failure's text lives in the catalog too: the controller maps the `Failure` to a key (errors.md).
